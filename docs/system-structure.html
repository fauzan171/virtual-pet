AI Air Canvas

Aplikasi menggambar di udara dengan webcam, MediaPipe Hand Landmarker, dan AI image generation.

Project: virtual-pet  |  Stack: Next.js, React, TypeScript

1. Struktur Utama

virtual-pet/ ├── app/ # Halaman dan API Next.js ├── components/ # Komponen UI React ├── lib/ # Logika bisnis dan utilitas utama ├── public/ # Asset statis ├── scripts/ # Skrip pengecekan manual └── file konfigurasi # Next.js, TypeScript, ESLint, PostCSS

2. Folder app/

app/page.tsx
Entry point halaman utama; merender komponen AirCanvas.
app/layout.tsx
Layout global, metadata, dan struktur HTML dasar.

Style global, layout fullscreen, warna, dan animasi.

Endpoint POST /api/generate. Memvalidasi PNG sketch, membersihkan subject voice command, memanggil engine AI, dan menyediakan mock mode.

Menu utama yang dibuka dengan gesture lima jari.
ColorPicker.tsx
Pemilih warna tinta.
ShapePicker.tsx

CalibrationOverlay.tsx
UI kalibrasi area tangan dan threshold pinch.
LoadingExperience.tsx
Tampilan saat gambar sedang dibuat AI.

Status kamera, tracking, drawing, dan generation.
DebugPanel.tsx
Informasi debug seperti FPS, landmark, dan frame tangan.

4. Folder lib/

Integrasi MediaPipe Hand Landmarker, ekstraksi landmark, pinch, dan gesture jari.
strokes.ts
Mengelola pembuatan, penyimpanan, dan render ulang stroke.
geometry.ts
Perhitungan jarak, pinch, deadzone, dan transformasi titik.
calibration.ts
Kalibrasi area kerja tangan dan threshold pinch.
one-euro.ts
Filter untuk mengurangi jitter dan menghaluskan kursor.
constants.ts
Konstanta model MediaPipe, kamera, gesture, warna, dan stroke.
types.ts
Tipe TypeScript seperti AppState, Point, Stroke, HandFrame, dan ShapeId.
agent.ts
Mengatur pemilihan image generation engine.
qwen-provider.ts
Provider Qwen untuk image-to-image generation; key tetap di server.
pollinations.ts
Fallback image generation gratis menggunakan Pollinations.
prompt.ts
Definisi style dan pembuatan prompt AI.
voice.ts
Voice command berbasis Web Speech API dan sanitasi subject.
sound.ts
Efek suara dan status audio aplikasi.

7. Alur Sistem

Webcam ↓ MediaPipe Hand Landmarker ↓ HandFrame + gesture detection ↓ Pinch / finger gesture ↓ DrawingCanvas ↓ PNG sketch ↓ POST /api/generate ↓ Qwen atau Pollinations ↓ Result screen

8. Ringkasan Arsitektur

AirCanvas.tsx berperan sebagai controller utama. Komponen di components/ menangani tampilan, sedangkan modul di lib/ menangani hand tracking, stroke, kalibrasi, suara, prompt, dan integrasi AI.

Webcam diproses lokal di browser menggunakan MediaPipe. Data video tidak dikirim ke server. Hanya PNG sketch yang dikirim ke endpoint generation ketika presenter memilih GENERATE.
